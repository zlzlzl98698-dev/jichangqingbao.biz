## 一、技术原理：机场后台是如何发现你超限的？

用户在购买多设备方案时最常混淆两个词：**“安装设备总数”** 和 **“同时在线源 IP 数”**。

当你使用 Clash Verge Rev 或 Shadowrocket 把同一条订阅 URL 导入电脑、iPad、iPhone 并打开连接时：
1. 如果这三台机器此时都在家里连着同一个路由器 Wi-Fi，对外向机场国内入口服务器发起 TCP/UDP 握手时，它们的源 IP 全部表现为家里宽带的**同一个公网 IPv4 地址**（如果家庭网络开了 NAT 转发）。
2. 如果你手机开着 5G 出门在地铁上用，而家里电脑挂在宽带上下大文件，这时候入口服务端在几分钟检测窗口里就会看到 **2 个不同归属运营商或不同城市网段的活跃源 IP**。
3. 一旦你将订阅共享给北京、广州、成都的 5 位好友同时全天候看高清视频，后台监测引擎就会在数小时内捕捉到多地并发高流量特征并触发限速甚至封号预警。

## 二、常见多终端场景与站内实测品牌兼容性对比

| 使用场景 | 活跃源 IP 估算 | 客户端支持前提 | 对应站内参考品牌方向 |
| :--- | :--- | :--- | :--- |
| 个人三端（PC + 手机 + iPad） | 同 Wi-Fi 为 1 个；外出切换 2 个 | 常规开放订阅或双支持 | 光速云、星岛梦、唯兔云、极连云、一翻云 |
| 全屋软路由（OpenWrt）+ 外出手机 | 家里全屋共用 1 个 + 手机 1 个 | **必须支持标准第三方订阅** | 剔除 8 家仅专属端，选 20 家开放订阅品牌 |
| 工作室多人混合办公 | 3–6 个以上动态源 IP | 需选用高并发企业/定制档 | 光速云定制等隔离方案，切忌普通版强行分摊 |

## 三、避免设备超限误杀的四项操作习惯

1. **家用首选 OpenWrt 网关**：只要先把家里路由器通过 OpenClash 或 Nikki 接好机场订阅，客厅里的电视盒、游戏机、平板与访客手机就都不需要各自单装代理也不多占独立 IP 名额（详见 [OpenWrt 软路由教程与兼容性](/clients/openwrt/)）。
2. **手机离开家或换网络前注意退出电脑后台高并发拉取**：减少不必要的多地域长时并发叠加。
3. **转赠或淘汰旧设备前必重置订阅 Token**：点击“重置订阅地址”即可一键作废历史设备上留存的旧订阅链接。
4. **切忌合租**：大多数低价个人套餐本来利润极薄，把订阅公开分享或低价拼单极易引发帐号违约被停且几乎 100% 不予退费（详见 [退款条款边界](/intelligence/refund-policy/)）。
